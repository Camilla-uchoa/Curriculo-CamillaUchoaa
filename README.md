Currículo Web — Camilla Uchoa

Versão online e interativa do meu currículo, desenvolvida para apresentar minhas informações profissionais de forma moderna, acessível e dinâmica.

A proposta do projeto é transformar o currículo tradicional em uma experiência navegável, facilitando a visualização das minhas habilidades, projetos, formação e trajetória profissional.

🌐 Aplicação Online

O projeto está publicado e pode ser acessado diretamente pela internet através da Vercel:

Acessar Currículo Web: https://pagecamillauchoa.vercel.app/


✨ Funcionalidades
Exibição de informações pessoais e profissionais
Organização das informações em seções
Apresentação da formação acadêmica
Exibição de habilidades técnicas
Apresentação de projetos
Informações de contato e links profissionais
Navegação simples e intuitiva
Layout responsivo para diferentes dispositivos
Interações utilizando JavaScript

🛠️ Tecnologias Utilizadas
HTML5 — estrutura e organização do conteúdo
CSS3 — estilização, layout e responsividade
JavaScript — interatividade e comportamento da aplicação
Git/GitHub — versionamento e gerenciamento do código
Vercel — publicação e hospedagem da aplicação

🚀 Como executar localmente

Clone o repositório:

git clone https://github.com/seu-usuario/Curriculo-CamillaUchoa-3C.git

Acesse a pasta do projeto:

cd Curriculo-CamillaUchoa-3C

Depois, abra o arquivo index.html no navegador.

Durante o desenvolvimento, também é possível utilizar uma extensão como Live Server no Visual Studio Code para executar a aplicação localmente.

⚡ Desempenho

A aplicação foi analisada utilizando ferramentas de avaliação de desempenho do navegador.

Resultados obtidos durante a análise:

Métrica	Resultado
First Contentful Paint	0,8 s
Largest Contentful Paint	12,4 s
Total Blocking Time	180 ms
Cumulative Layout Shift	0,272
Speed Index	0,9 s

Os resultados demonstram um carregamento inicial rápido, com First Contentful Paint de 0,8 s e Speed Index de 0,9 s.

O projeto ainda possui oportunidades de otimização, principalmente relacionadas ao Largest Contentful Paint (LCP) e ao Cumulative Layout Shift (CLS), que poderão ser trabalhadas em versões futuras.

Entre as melhorias planejadas:
